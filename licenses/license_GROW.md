# General information

Data from the global-scale integrated GROundWater package (GROW) (groundwater quantity, observations, monitoring station latitude and longitude) included in GROW-Qual was retrieved from Zenodo (https://doi.org/10.5281/zenodo.15149480). GROW represents an aggregated database with heterogeneous licensing, which is fully described in the metadata of GROW.
