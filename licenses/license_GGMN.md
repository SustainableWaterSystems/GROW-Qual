# General information

Data from the Global Groundwater Monitoring Network (GGMN) (groundwater quantity and quality observations, monitoring station latitude and longitude) included in GROW-Qual was retrieved from the GGMN web portal (https://ggis.un-igrac.org/groundwater/record/download). It represents an aggregated database with heterogeneous licensing, which is fully described in GGMN's metadata.
